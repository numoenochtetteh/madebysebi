MadeBySebi launch notes — 26 September 2026
==========================================

Website: https://madebysebi.com
Repository: https://github.com/numoenochtetteh/madebysebi
Hosting: Vercel project madebysebi

Current setup
-------------
- Both madebysebi.com and www.madebysebi.com resolve to the website.
- Public email links and structured data use hello@madebysebi.com.
- Contact enquiries go to hello@madebysebi.com through the verified
  madebysebi.com sending domain in Resend.
- Namecheap Private Email handles incoming mail. Resend Receiving remains off.
- Vercel Web Analytics and Speed Insights are mounted in the root layout.
- Site metadata, sitemap and robots use https://madebysebi.com by default.

Production environment variables in Vercel
------------------------------------------
RESEND_API_KEY       = the active sending key restricted to madebysebi.com
CONTACT_TO_EMAIL     = hello@madebysebi.com
CONTACT_FROM_EMAIL   = MadeBySebi Website <hello@madebysebi.com>

The API key must stay in Vercel, never in Git or a shared ZIP. The site code
contains a matching sender and recipient fallback, but delivery still requires
RESEND_API_KEY. NEXT_PUBLIC_SITE_URL is optional; the default is madebysebi.com.

Changes in this handoff
-----------------------
- Updated visible contact addresses, form fallbacks, Resend fallbacks and schema.
- Gave the homepage's featured image high fetch priority without preloading
  the logo. Other hero images remain lazy loaded.
- Set the known custom domain as the default URL for SEO metadata and sitemap.
- Updated the environment example and these notes to match the live setup.

Verification and deployment
---------------------------
1. In the real Git repository, copy these updated project files over the
   existing files. Keep the repository's .git directory and Vercel settings.
2. Run: pnpm install --frozen-lockfile
3. Run: pnpm build
4. Review: git status --short
5. Run: git add -A
6. Run: git commit -m "Polish MadeBySebi launch and mobile loading"
7. Run: git push origin main
8. Once Vercel deploys, check the homepage, Contact email link and a test
   enquiry. Run PageSpeed Insights again and compare the mobile result.

Speed Insights showed a mobile score of 30 based on only six events, so it is
not a stable estimate yet. A separate PageSpeed Insights mobile test on the
live site scored 89, with 100 for accessibility, best practices and SEO.
